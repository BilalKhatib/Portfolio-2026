# Bilal Khatib — immersive cyber portfolio design assets

A usable starter package matching the **art direction** of the portfolio concept generated in the conversation.

## What's included
- Original uploaded portrait (`portrait/bilal-original.jpg`)
- Original homepage mockup and expanded design/art direction board (`references/`)
- 4 independent SVG backgrounds, 3 UI illustrations/icons, and 6 project illustrations
- Generated transparent star texture overlay
- Design token JSON, CSS utility starter, agent build instructions and an asset map

## Limitations / important
This is **not the original editable source scene** of the AI-generated picture. The picture is flattened, and the 3D models do not exist as separate GLB/FBX assets. The included SVGs are newly drawn approximations intended to enable faithful implementation. An accurate transparent subject cutout still needs to be produced by an image editor. Please don't claim pixel-perfect fidelity or real 3D purely from these images.

Open `docs/ASSET-MAP.md` and `docs/AGENT-BUILD-INSTRUCTIONS.md` before you start.
